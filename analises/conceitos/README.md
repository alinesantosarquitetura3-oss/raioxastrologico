# Fichas conceituais

Aqui serão desenvolvidos os conceitos próprios do método antes de sua incorporação definitiva ao escopo.

Cada ficha deverá responder:

- O que significa este conceito no Raio-X Astrológico?
- Qual problema ele ajuda a compreender?
- Quais códigos ou elementos astrológicos se relacionam a ele?
- Como se distingue de conceitos psicológicos, terapêuticos ou espirituais próximos?
- Quais fontes sustentam sua formulação?
- Quais limites e cuidados de linguagem devem ser observados?
- O conceito já foi validado por Aline?
