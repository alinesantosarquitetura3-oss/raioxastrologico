# Repertório Madame Aline

Esta pasta reúne conteúdos fornecidos ou exportados pela autora a partir da Madame Aline, preservando a origem e o contexto de cada resposta.

Para cada registro, incluir sempre que possível:

- pergunta ou comando utilizado;
- resposta completa;
- data da consulta;
- tema principal;
- observações da autora sobre o que representa ou não o seu método.

O link público do GPT é uma referência de acesso, mas não substitui o conteúdo efetivamente fornecido para análise. Cada resposta relevante deverá ser registrada aqui para que o raciocínio do projeto permaneça rastreável.
