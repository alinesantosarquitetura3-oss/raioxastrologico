# Transcrições

Esta pasta recebe as transcrições originais dos vídeos usados como fonte.

## Convenção de nome

Use:

```text
AAAA-MM-DD__autor-ou-canal__titulo-curto.md
```

Quando a data original não estiver disponível, use `sem-data`.

## Cabeçalho sugerido

```markdown
# Título do vídeo

- Fonte:
- Autor ou canal:
- URL:
- Data de publicação:
- Data de inclusão:
- Tipo de transcrição: automática | revisada | manual
- Observações:

## Transcrição
```

O texto original deve ser preservado. Correções, interpretações e relações com a mentoria pertencem à pasta `analises/`.
